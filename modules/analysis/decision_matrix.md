# Core Decision Matrix

Regime states for equity / VIX / catalyst alignment. Playbook is the correct
response *in that state*, not a forecast of the next state.

| State | Equity behavior | VIX behavior | Information / catalyst | Interpretation | Correct playbook |
| --- | --- | --- | --- | --- | --- |
| **G — Clean Risk-On** | HH/HL, smooth trend ↑ | ↓, new lows, old floor intact | No worsening threat being priced | Healthy bull regime | **Long bias. Leverage allowed. Buy pullbacks. Let winners run.** |
| **Y — Mature / Event Divergence** | Stocks ↑ or near highs | VIX ↑ / higher lows / refuses to fall | Major scheduled catalyst or uncertainty | Distribution widening; market disagreement | **Stop adding. Reduce event exposure. Wait for resolution, then attack.** |
| **R — Clean Correction** | Smooth ↓, LH/LL | Smooth ↑ | Risk increasingly recognized | Price and vol agree | **Delever longs. Short/hedge trend. Use MACD to stay with move.** |
| **H — Hard Mode / Distribution** | Chop, failed rallies, overlapping swings | Elevated chop; higher floor | No single decisive catalyst required | Neither side controls trend | **Small 3–7D swings both directions. Lower gross. Avoid conviction beta.** |
| **D — Low-Vol Deleveraging** | Stocks/sectors ↓ | VIX flat or ↓ | Often positioning rather than systemic fear | Capital leaving without broad panic | **Trade weak groups/dispersion. Short duration. Don't expect index crash automatically.** |
| **N — Denial / Latent Shock** | Stocks remain resilient or keep recovering | VIX begins ↑ and forms higher lows | **Known threat progressively worsens** | Risk is accumulating faster than equity recognition | **Proactively delever. Add convexity. Don't wait for price breakdown.** |
| **F — Forced Recognition** | Sharp breakdown / gaps ↓ | VIX accelerates | Threat finally accepted or sudden shock | Everyone now sees the risk | **Manage existing shorts/hedges; don't blindly chase extension. Follow only while structure persists.** |
| **B — Exhaustion / Repair** | Bad news fails to create new lows | VIX peaks / lower high / ↓ | Threat remains scary but market stops responding | Risk has become saturated | **Cover shorts. Start releveraging. Buy repaired structure.** |

## Put-trade evaluation map

How a **long put** should be judged *at entry* against this matrix:

| Entry state | Aligned put? | Typical failure if misused |
| --- | --- | --- |
| G | No | Chasing a signal that does not exist |
| Y | No (wait) | Too early; paying event premium before resolution |
| R | Yes — trend short/hedge | Outstay if held into B |
| H | Yes only as small 3–7D swing | Outstay if conviction-sized or held >7D |
| D | Yes on weak names; no on index-crash | Chasing crash that vol is not confirming |
| N | Yes — convexity / proactive hedge | Too early only if VIX higher-lows are a blip (still G) |
| F | Only manage / follow structure | Chasing extension after the move is obvious |
| B | No — cover | Late / outstayed; fading a repair |

## Call-trade evaluation map

How a **long call** should be judged *at entry* against this matrix:

| Entry state | Aligned call? | Typical failure if misused |
| --- | --- | --- |
| G | Yes — pullbacks and trend | Cutting winners; or holding after the tape leaves G |
| Y | No (wait) | Too early; paying event premium before resolution |
| R | No — delever | Catching a clean correction |
| H | Yes only as small 3–7D swing | Outstay if conviction-sized or held >7D |
| D | Yes on strong/leader names only | Catching weak names or buying index beta while capital leaves |
| N | No — delever / add put convexity | Fighting latent shock; calls invent a clean dip |
| F | No — do not buy the breakdown | Knife-catch; the call side of F is **wait for B** |
| B | Yes — relever into repaired structure | This is how you monetize the other side of F |
